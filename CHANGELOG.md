# Changelog

## 0.4.0 — Campaign development and native party stash

- Add persistent Memories and daily Shrouds, including reveal permissions, prerequisites, capacity and optional source benefits.
- Add Curio bearers, level/milestone gates, gift reveal controls, campaign tags, source previews and explicit benefit synchronization.
- Add rune equipment targets and compatibility feedback; supported temporary weapon effects are opt-in. Armor/accessory automation stays manual.
- Add Carriage Outfit, GM-reviewed projects, campaign export/import and scoped, recoverable operation records.
- Make Cargo & Treasury open PF2E's actual native stash. Remove the reduced inventory page and new custom supply requests. Keep old pending requests recoverable.
- Remove Caravan Overview, People, player My Requests and Activity navigation while retaining saved data. Rename Facilities to Carriage Outfit.
- Add talent editor undo/redo, alignment, duplication, search, minimum levels, per-rank costs/sources and dependency-aware refunds.
- Add consumable saved/draft status, removed-option reconciliation and the Storyteller preparation roster; preserve existing quantity bands and Dailies grants.
- Preserve Base 1 data through additive campaign migration and player-specific projections.
- Add a license-free interactive renderer using production assets, seven Node test files and twelve browser campaign scenarios. Native sheet handoff is explicitly simulated.

New source-linked mechanical benefits are **disabled by default** and native integration validation remains outstanding. No live Foundry/PF2E/Dailies testing is claimed. Compatibility declaration remains Foundry 14.369.
